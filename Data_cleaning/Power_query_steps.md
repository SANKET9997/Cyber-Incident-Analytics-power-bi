# Power Query – Data Cleaning & Transformation

## Data Sources

The Cyber Incident Analytics project uses multiple CSV datasets covering global incidents, receivers,
 attribution, and dyadic relationships.

## Data Cleaning Steps

1. Connected the CSV datasets to Power BI using Power Query.
2. Promoted the first row as headers.
3. Changed columns to appropriate data types.
4. Reviewed and handled missing/null values.
5. Parsed and standardized incident date fields.
6. Validated incident IDs and key columns.
7. Checked receiver, attribution, and impact-related data for consistency.
8. Loaded the cleaned tables into the Power BI data model.

## Key Transformations

- Promoted Headers
- Changed Data Types
- Date Parsing
- Null/Missing Value Handling
- Data Validation
- Column Standardization

## Outcome

The cleaned datasets were prepared for data modelling, DAX calculations, 
and interactive Power BI dashboard analysis.
